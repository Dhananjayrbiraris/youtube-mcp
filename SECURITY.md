## Reporting a Vulnerability

If you discover a security vulnerability or sensitive credential exposure risk in this repository, please do **NOT** open a public issue.

Instead, please send an email to **dhananjay.biraris@facileserv.com** with:
- Description of the issue
- Steps to reproduce
- Potential impact

We take security seriously and will respond promptly to investigate and patch any reported issues.
